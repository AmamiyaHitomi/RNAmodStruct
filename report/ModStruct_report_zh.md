# ModStruct：人类 m6A 修饰水平与局部 RNA 结构信号的关联及预测分析

**结题报告（含 HEK293T 发现集与 HeLa 复核集）**

---

## 摘要

本研究整合公开的 GLORI 单碱基 m6A 定量数据与 icSHAPE 实验结构探测数据，在"已检出且通过质控"的
mRNA 位点上，考察局部实验结构信号（±10 nt 平均反应性 R_flank10）与 m6A 修饰比例的关系，并通过
序列、预测结构与实验结构的模型消融评估实验结构的额外预测价值，最后以 HeLa 数据复核关联与迁移。

主要结果：

1. **关联（Q1，HEK293T）**：R_flank10 与 m6A 比例呈小的正向关联，结构信号每升高 1 个标准差，
   修饰比例升高约 1.43 个百分点（聚类稳健 95% CI 0.60–2.26，基因聚类 bootstrap CI 0.65–2.28，
   p = 7.9×10⁻⁴）；七项预设敏感性分析全部保持正向。
2. **预测（Q2，HEK293T）**：在固定测试集上，实验结构（M3）相对序列基线（M1）的 ΔMAE 为
   −0.003 个百分点（CI −0.034 至 +0.025）；预测结构（M2）反而比 M1 差约 0.65 个百分点。未观察到
   可靠的额外预测增益。
3. **复核（Q3，HeLa）**：关联在 HeLa 成功复现（+0.00947/SD，CI +0.0063 至 +0.0126，p = 3.5×10⁻⁹，
   方向一致、幅度略小）；但冻结的 HEK293T 预测模型直接迁移到 HeLa 时，实验结构未带来增益
   （ΔMAE = MAE(M1)−MAE(M3) = −0.064 个百分点，严格子集 −0.063），且背景模型 M0 迁移后表现最好。

结论：**"局部实验结构信号与 m6A 修饰比例正相关"这一关联在两个细胞系中都成立；但实验结构信号相对
序列基线没有表现出可靠的预测增益。** 这一结论受限于观察性、跨研究、跨批次设计，不能作因果解释。

---

## 一、研究问题

| 问题 | 内容 | 结果 |
|---|---|---|
| Q1 | 已检出 m6A 位点的修饰比例是否与邻域结构信号相关？ | 正向关联，两细胞系一致 |
| Q2 | 实验结构是否提高对修饰比例的预测？ | 无可靠增益 |
| Q3 | 结果是否跨数据集稳健？ | 关联复核通过；预测迁移无增益 |

响应变量为连续的 m6A 修饰比例（GLORI `Ratio` 的计数加权合并值 `combined_ratio`），主结构指标为
`R_flank10`（中心两侧各 10 nt 有效反应性均值，两侧分别 ≥70% 有效值）。研究对象是"已检出且通过质控
的位点"，结论不能推广为全转录组所有 A 位点的规律。

## 二、数据与方法

### 2.1 数据

| 用途 | 数据集 | 样本 | 说明 |
|---|---|---|---|
| 发现集结构 | GSE74353 | HEK293T icSHAPE in vivo | 10,164 转录本，GRCh37.74/hg19 |
| 发现集 m6A | GSE210563 | GSM6432590/91（HEK293T GLORI rep1/2） | GRCh38，处理后 14 列表格 |
| 复核集结构 | GSE145805 | GSM4333258 HeLa（NAI-N3 处理后） | 64,616 版本化转录本，hg38 |
| 复核集 m6A | GSE210563 | GSM6432595/96（HeLa hypoxia- GLORI rep1/2） | GRCh38，常氧对照 |

坐标统一：HEK293T 的 icSHAPE 转录本坐标经 GRCh37.74 注释映射到 hg19，再经 hg19→hg38 liftOver 对齐
GLORI 的 GRCh38 位点；HeLa 的 icSHAPE 为 hg38（版本化 Ensembl ID），直接与 GRCh38 位点映射，匹配
Ensembl release 88。反向链基因组参考碱基为 T，但转录本方向的中心碱基必须为 A。

### 2.2 筛选流程

| 步骤 | HEK293T | HeLa |
|---|---:|---:|
| GLORI 并集 | 253,087 | 164,761 |
| 映射到 icSHAPE 转录本 | 20,559 | 86,932 |
| 两重复均检出 | 16,161 | 65,050 |
| 主结构集（±10 nt ≥70% 有效） | 4,409 | 25,996 |
| 模型就绪（完整 201 nt） | 4,096 | 24,960 |

### 2.3 统计与模型

- **关联模型**：`combined_ratio ~ R_flank10 + 协变量`，普通最小二乘 + 按基因聚类的稳健协方差（CR1），
  并以 1,000 次基因聚类 bootstrap 复核。协变量：DRACH 子型、转录本区域、局部 GC、距终止密码子距离、
  距剪接边界距离、log1p 覆盖深度、log1p 表达量（HEK293T）。
- **预测模型**：M0（背景）、M1（背景+序列 one-hot 与 3-mer）、M2（+预测结构）、M3（+实验结构）、
  M4（+两者）五类 Ridge 回归，alpha ∈ {0.01, 0.1, 1, 10, 30, 100, 300, 1000, 3000}，5 折 GroupKFold
  调参；若最优值落在网格边界则拒绝冻结。以基因 + 相同 201-nt
  序列的连通分量为独立分组，80%/20% 一次性划分。
- **预测结构**：ViennaRNA 2.7.2 配分函数（37°C，dangles=2）的未配对概率、MFE/nt、ensemble 自由能、
  配对状态熵。
- **复核与迁移**：HeLa 用冻结规则重建表并独立重估关联；冻结的 HEK293T 模型与预处理直接预测 HeLa，
  分别报告全部合格位点与"剔除与 HEK293T 开发集基因/序列重叠"的严格子集。

## 三、结果

### 3.1 Q1：HEK293T 关联分析

| 指标 | 值 |
|---|---|
| 位点 / 基因 | 4,409 / 1,324 |
| β（每 SD 反应性） | +0.01430 |
| 聚类稳健 95% CI | +0.00595 ~ +0.02264 |
| 基因聚类 bootstrap 95% CI | +0.00650 ~ +0.02276 |
| p | 7.9×10⁻⁴ |
| 约合每 SD | ≈1.43 个百分点 |
| R² | 0.174 |

七项预设敏感性分析（排除 −2..+2、仅完全覆盖、两个 GLORI 重复分别、每基因等权、仅无异构体歧义、
仅常规 DRACH）全部为正向，BH 校正后 q ≤ 0.034。诊断显示存在异方差（推断用聚类稳健协方差）与非线性
（RESET p = 1.9×10⁻¹⁵，样条略优，AIC 差 −1.72）。区域分层中 3′UTR 与 CDS 正向，5′UTR 与其他区域为
负但区间跨零。

### 3.2 Q2：HEK293T 预测消融

| 模型 | 输入 | 测试 MAE（百分点） |
|---|---:|
| M0 | 背景 | 20.82 |
| M1 | 背景+序列 | 20.55 |
| M2 | +预测结构 | 21.19 |
| M3 | +实验结构 | 20.55 |
| M4 | +两者 | 21.19 |

主要比较 ΔMAE = MAE(M2) − MAE(M4) = +0.005 个百分点（配对组 bootstrap 95% CI −0.018 至 +0.027），
未检测到实验结构相对"序列+计算结构"基线的可靠增量；预测结构（M2）反而比 M1 差 0.65 个百分点。另
以 M3 对 M1 的 −0.003 个百分点（CI −0.034 至 +0.025）同样无可靠增量。08B 开发集诊断中，任何扩展
实验结构块都不优于 M1，冻结 R_flank10；GLORI 重复间 MAE 为 2.65 个百分点（远小于模型误差约 20.5），
说明重复噪声不足以解释模型误差。

> 注意：HEK293T 测试集标签在预处理修正前已被查看，故内部测试结果标为"复用测试集"，描述性结论；
> 独立验证依赖 HeLa 阶段。

### 3.3 Q3：HeLa 复核

**关联复核**（25,996 位点 / 4,829 基因）：

| 指标 | HEK293T | HeLa |
|---|---:|---:|
| β（每 SD） | +0.01430 | +0.00947 |
| 聚类稳健 95% CI | +0.00595 ~ +0.02264 | +0.00633 ~ +0.01261 |
| bootstrap 95% CI | +0.00650 ~ +0.02276 | +0.00643 ~ +0.01271 |
| p | 7.9×10⁻⁴ | 3.5×10⁻⁹ |

关联方向一致、区间均排除零，幅度略小（约 0.95 vs 1.43 个百分点/SD）；七项敏感性全部正向；效应集中
在 3′UTR（+0.0124/SD，q = 2.5×10⁻⁹）。

**预测迁移**（冻结模型直接预测 HeLa，24,960 全部 / 22,256 严格子集）：

| 模型 | 全部 MAE（百分点） | 严格子集 MAE（百分点） |
|---|---:|---:|
| M0 | 20.52 | 20.56 |
| M1 | 21.61 | 21.86 |
| M2 | 21.89 | 22.21 |
| M3 | 21.67 | 21.92 |
| M4 | 21.95 | 22.26 |

主比较 ΔMAE = MAE(M1) − MAE(M3) = −0.064（全部）/ −0.063（严格）个百分点，bootstrap 区间完全为负：
实验结构未带来增益，且冻结的序列/结构特征迁移后表现反而低于仅含背景的 M0，说明 HEK293T 上拟合的
序列/结构特征未迁移出其优势。

## 四、讨论

1. **关联稳健、幅度小**。两细胞系都给出正向且区间排除零的关联，方向可复现；但每 SD 约 1 个百分点的
   幅度属于"小效应"，且存在非线性、区域异质性（3′UTR 主导）。
2. **预测增益缺失是如实结果**。实验结构反应性并非序列的确定性函数，理应有独立信息；但在当前 Ridge
   基线和位点群体上，无论 HEK293T 内部测试还是 HeLa 迁移，都没有检测到它对预测误差的可靠降低。这与
   "关联存在但预测无增益"并不矛盾——统计关联与额外预测价值是不同的估计量。
3. **迁移失败不能单一归因**。HeLa 与 HEK293T 的研究年份、处理流程、培养条件均不同，细胞系差异与批次
   差异纠缠；覆盖、异构体构成与表达差异也是候选解释，不能归结为"细胞特异性"。
4. **解释边界**。icSHAPE 反应性是结构相关测量，不是配对概率；观察性、跨研究设计不能作因果推断；调整
   仅覆盖列出的协变量；同基因与同源序列依赖的处理有实际边界。

## 五、限制

- 研究对象是"已检出且通过质控"的位点，存在选择与 collider 偏倚，不推广到全转录组。
- 仅约 52.8%（HeLa）/ 8.1%（HEK293T）的 GLORI 并集位点能映射到 icSHAPE 转录本，筛选损失大且非随机。
- HeLa 的 icSHAPE 无表达量字段，关联模型缺失该协变量；迁移时用 HEK293T 开发集中位数插补。
- 计算结构改善属于表征增益，不等于发现了序列之外的独立生物信息。
- Q4（修饰/低修饰分类）未开展，因缺乏合格的低修饰背景数据。

## 六、结论

在 HEK293T 与 HeLa 两个细胞系中，局部实验结构信号与 m6A 修饰比例之间存在方向一致、区间排除零的
正向关联；但实验结构信号相对序列基线未表现出可靠的预测增益。本工作提供了一个范围清晰、可复现的
实证分析，明确区分了"关联"与"预测价值"两个层次，并如实报告了零增益与迁移失败。
