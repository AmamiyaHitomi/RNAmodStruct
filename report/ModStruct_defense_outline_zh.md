# ModStruct 答辩提纲

## 一句话定位

用公开的 GLORI（m6A 定量）与 icSHAPE（RNA 结构探测）数据，在已检出且通过质控的 mRNA 位点上，
回答两个层次的问题：**局部结构信号与修饰比例是否相关（关联）**，以及**结构信号能否提升对修饰比例
的预测（预测价值）**，并在 HeLa 上复核。

## 建议讲解顺序（约 10–12 分钟）

1. **问题与动机（1 min）**
   - m6A 与局部结构已知相互关联（2015 icSHAPE、m6A-switch；2024 Shachar；2026 SMART-m6A）。
   - 本项目不争"是否相关"的首创，而是做**范围清晰、可复现的实证**：分开"序列表征增益"与
     "实验测量增益"，在严格划分与外部复核下量化结论的成立条件。

2. **数据与对齐（2 min）**
   - 图 1：两组数据的来源、样本条件、筛选流程与最终位点/基因数。
   - 强调难点：跨研究、跨年份、跨参考版本的对齐（HEK293T 需 GRCh37→hg38 liftOver，HeLa 为
     hg38 直接映射 + 版本化 Ensembl ID）；中心碱基必须为 A，反向链参考为 T。

3. **Q1 关联（2 min）**
   - 图 3（效应森林图）：R_flank10 每 SD 对应约 +1.43 个百分点修饰比例，基因聚类 bootstrap
     CI 排除零；七项敏感性全部正向。
   - 边界：观察性、小效应、3′UTR 主导、非线性。

4. **Q2 预测（2 min）**
   - 图 4（M0–M4 MAE）：预测结构 M2 反而比序列基线差 0.65 个百分点；实验结构 M3 相对 M1 无
     可靠增量。
   - 关键点：**统计关联 ≠ 额外预测价值**；预测结构是序列的确定性函数，增益只能叫"表征增益"。

5. **Q3 复核（2 min）**
   - 图 5：关联在 HeLa 复现（方向一致、区间排除零、幅度略小）；但冻结模型迁移无增益，
     M0 迁移后反而最好。
   - 迁移失败不能单一归因于"细胞特异性"（批次、覆盖、培养条件纠缠）。

6. **结论与限制（1–2 min）**
   - 结论：关联两细胞系一致；预测增益未检测到。
   - 主动说明：零增益与迁移失败是如实交付，不是失败的研究；Q4 未做（缺背景数据）。

## 预期被问的问题与应答要点

- **"关联有、预测没有，矛盾吗？"** 不矛盾。关联回答"在给定协变量下结构信号与修饰比例是否共同变化"；
  预测回答"结构信号能否在未见样本上降低预测误差"。两者是不同的估计量。
- **"预测结构为什么没用？"** 它是序列的确定性非线性变换，有限 Ridge 模型未必受益；这是表征层面的
  结论，不等于计算结构生物学上无关。
- **"HeLa 迁移失败说明什么？"** 说明 HEK293T 上拟合的序列/结构特征未泛化；细胞系、批次、覆盖、
  表达差异纠缠，不能单一归因。
- **"样本筛选损失大、有偏吗？"** 有。仅小部分 GLORI 位点能映射到 icSHAPE，且依赖检测与覆盖，属于
  selection/collider 偏倚；结论限定在"已检出且通过质控"的群体。
- **"能不能说结构影响修饰？"** 不能。观察性、跨研究设计无法确定方向；只能说"相关"。
