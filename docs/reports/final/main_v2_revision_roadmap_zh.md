# ModStruct main_v2 投稿前修订路线图

状态：阶段 0–2 已完成；阶段 3 最低交付范围已完成、详细扩展未执行；阶段 4 技术复现已完成，投稿格式仍待目标会议确定  
依据：[投稿前审阅记录](main_v2_presubmission_review_zh.md)与[修订实施方案](main_v2_revision_implementation_plan_zh.md)  
目标：让每项结论对应明确的分析人群、特征和模型、验证角色及不确定性范围。

## 一、论文主线与执行原则

目前可支持的主线应限定为：在经过筛选且有足够结构覆盖的已检测位点中，实测局部 icSHAPE 反应性与 GLORI 修饰比例存在小幅正向关联；在当前特征、学习器与冻结跨细胞系迁移设计下，该关联没有转化为预测收益。这是有条件的经验结果，不能推广为实验 RNA 结构普遍没有预测价值。

审阅记录报告，HeLa 外部评估中 M0 MAE 为 0.20515、M1 为 0.21608，序列特征对应误差增加约 1.093 个百分点；M1 到 M3 的实验结构增量恶化约 0.0641 个百分点。这些是路线图的输入数字，实施时须由冻结逐位点预测复核。明确每张表中 ΔMAE 的计算方向，并区分比例单位与百分点。

所有新增分析标为后续／事后敏感性分析；不能改写成外部预注册结果，也不能将已经查看过的内部测试集重新称为未触碰测试集。先固定比较、集合和估计规则，再运行新增 HeLa 比较；不得按 HeLa 结果挑选候选模型或分组。

### 阶段 0：固定证据边界

1. 按文件与提交记录整理：首次查看内部测试集、预处理／缩放修正、预测结构加入、Ridge alpha 网格扩展、HeLa 首次评估，以及 401nt 和 HGB 后续分析。核对决策日志中早期主对比与正文所称内部主对比的差异；不能证明的历史状态写为 `unknown`，不补造时间点。
2. 检查 `config/17_nonlinear_models.yaml`、正文和补充材料，统一 HGB 分析的 validation role；避免将后续分析写成 `untouched_external_evaluation`。
3. 在新增分析前保存并哈希三组 HeLa `site_id`：全体合格位点、现有“排除 HEK293T development 重叠”集合、可审计范围内“排除所有曾查看的 HEK 位点重叠”集合。另记录基因排除、相同 201nt 序列排除及各集合交集。第三组仍是事后敏感性集合，不称为未查看验证。
4. 明确现有 strict 集合只排除 HEK293T development 重叠，不代表排除了全部曾查看 HEK 位点或广义同源序列。
5. 预先列出每项比较的方向、分析人群、模型与区间解释。外部评估采用同一联合分组配对 bootstrap 索引，按 joint group 抽样 2,000 次，区间字段标记 `CI_scope=fixed_fitted_models`。

### 阶段 1：冻结预测诊断，无需重训练

对 HEK293T 测试集、HeLa 全体和现有 development-overlap-excluded 集合，报告 MAE、RMSE、Spearman、R²、误差均值、预测裁剪比例、预测分布及按开发集分箱确定的校准曲线。先读取已保存的逐位点预测；若仅有汇总表，则恢复原冻结模型并以原结果核对，不能以重新拟合替代原冻结结果。

加入仅用 HEK293T development 标签中位数确定的常数预测。HeLa 标签中位数可以单列为 oracle 诊断，不能作为可部署基线。复核审阅记录已列的账目：`230866 + 939 + 722 + 1 + 20559 = 253087`、`3271 + 825 = 4096`、`24960 - 2704 = 22256`，以及表 2 固定效应合并值约 1.007 个百分点。若复核不符，先查清样本和单位定义再推进。

### 阶段 2：关键匹配模型比较

| 比较 | 执行要求 | 回答的问题 |
|---|---|---|
| M0 vs M0＋实验结构 | 其余训练与评估条件一致 | 结构能否改善简单背景模型 |
| 去除 icSHAPE abundance | 对 M0、M0＋结构、M1、M3 在训练前删特征，重新训练并调参；不能只在 HeLa 填零 | 缺失 abundance 对迁移结论的影响 |
| Ridge vs HGB | 相同 3-mer 表示、相同训练范围和分组划分 | 阴性结果是否依赖学习器 |

固定原 development／test 划分和五折分组。所有类别发现、缩放、预处理及 alpha 选择均在训练折内进行。先保存所有预定模型和 CV 结果，再统一做外部评估；不依据 HeLa 指标回头筛选。每个外部对比使用阶段 0 固定的集合和配对索引。bootstrap 区间只描述当前已拟合模型在评估群体上的抽样不确定性，不覆盖重新抽取训练位点、重新调参或更换特征表示的不确定性。

### 阶段 3：关联分析与样本选择解释

**结项口径：最低交付范围完成。** 已交付 stage 19 估计量核对、HeLa 两个重复特异 `NormeRatio` 敏感性、结构覆盖平衡和固定 3 自由度样条诊断。该结项不包含原详细实施方案提出的两细胞系 AGcov 加权 pooled `NormeRatio`、标签差值／相关性／coverage 分层、共同尺度 raw-slope 对比与至少 2,000 次配对基因 bootstrap，也不包含可选的基因内／基因间分解。现有 500 次 bootstrap 比较的是按各条件自身 SD 标准化的系数，不能写成共同物理尺度下的斜率差。

1. 从 stage 19 现有结果提取体内／体外原始斜率、各条件反应性 SD、标准化斜率及区间，另报告配对差异。定义图 2C 的 `Δ reactivity`。由于两个条件按各自 SD 标准化，标准化系数之差不能直接解释为同一物理尺度上的结构响应差异。
2. 保持 count-pooled Ratio 为主标签，新增 `NormeRatio` 敏感性分析；不能用两个重复的简单均值替代主标签。
3. 对 HeLa 结构覆盖合格和不合格位点制作协变量平衡表，说明结论所适用的筛选人群。
4. 用已有样条诊断绘制调整曲线与反应性分布，不依据曲线反复寻找有利子组。
5. 基因内／基因间分解是可选增强；若未完成，不把基因聚类稳健标准误表述为已完全控制基因层面混杂。

### 阶段 4：文稿、图表与复现包

**论点与措辞。** 在引言和 §4.2 承认 SMART-m6A 已包含 GLORI 连续修饰强度预测。将本研究差异写为实测 icSHAPE、背景与序列信息之外的条件增量、HEK293T 训练到 HeLa 的冻结迁移，以及可审计的数据整合；不再以“前者分类、本文回归”作为主要空白。将 Fig. 4 的 `reject an experimental-structure gain` 收窄为 `did not improve the evaluated transfer models`，并根据匹配比较结果进一步校准全文结论。正文准确指向补充材料中的 GLORI 字段公式、M0 特征清单、Ridge alpha 网格、冻结模型和 bootstrap 范围说明。

**复现交付。** 明确指定 `main_v2` 或新修订稿的构建入口；现有默认编译 `main` 的脚本不能视为 `main_v2` 构建。扩展 release manifest，覆盖代码版本、论文源码、图表、配置、环境锁定、输入校验值、最终样本 ID、分组划分、冻结模型、特征字典、结果表及必要子模块，并保留旧版本文件。README 给出从输入到图表/PDF 的命令和最小运行示例。核查 `validate_evidence.py` 是否覆盖 `main_v2` 与新增结果；旧检查通过不等于新结果已验证。记录实际 Python 环境、依赖、CPU、内存和运行时间。

分别执行两级验收：A级，从冻结表重建图表和 PDF；B级，从 processed 输入重建划分、模型和指标。最后按目标投稿模板逐页检查 PDF；原审阅只报告当前 10 页 PDF 无明显裁切、重叠或缺字，部分图中文字偏小，不能替代最终版式验收。目标期刊或会议尚未确定，因此不预称已满足特定投稿规范。

## 三、依据结果选择结论

| 阶段 2 的结果 | 论文应如何表述 |
|---|---|
| 匹配对照仍未见结构增益 | 保留限定范围的阴性预测结论，明确人群、特征、学习器和冻结迁移条件 |
| 仅特定基线、学习器或协变量设置下出现增益 | 改写为条件依赖结果，完整报告全部预定比较，不单独突出有利设置 |
| 冻结结果无法复现或样本账目不一致 | 暂停对外部预测结果作定论，先修复数据、模型与结果表的对应关系 |

整体定位宜为公共数据整合、可复现基准及限定范围的阴性结果研究，而非新预测算法或性能领先论文。完成标准不是得到某个方向的 ΔMAE，而是证据、方法与表述相互一致。

## 四、最低交付包与增强项

**最低交付包：已完成。** 阶段 0 的时间线与集合定义；阶段 1 的冻结预测和常数基线诊断；阶段 2 的三类匹配比较；阶段 3 的估计量、两个重复特异 `NormeRatio` 敏感性、HeLa 覆盖平衡和样条诊断；阶段 4 的文稿、补充材料及 A/B 两级技术复现验收。每项保留输入、代码版本、输出路径和核对结果。目标会议尚未确定，因此此处不包含会议模板、页数和匿名规则验收。
